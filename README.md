# Математика без страха

Интерактивный русскоязычный курс математики с подробными и понятными объяснениями — от обычных примеров и переменных до уравнений, бесконечности и построения графиков.

Курс предназначен для людей, которым сложно воспринимать стандартные школьные объяснения. Каждая тема разбирается постепенно: что означает запись, из каких частей она состоит, почему выполняется конкретное действие и как проверить ответ.

## Возможности

* 15 последовательных учебных разделов;
* 60 самостоятельных заданий;
* пошаговые объяснения решений;
* подсказки без немедленной выдачи ответа;
* интерактивный разборщик структуры выражений;
* дроби, степени, корни и переменные;
* линейные и простые квадратные уравнения;
* проценты, пропорции и неравенства;
* понятное объяснение бесконечности;
* интерактивная лаборатория графиков;
* сохранение прогресса в браузере;
* режим увеличенного текста;
* адаптация для компьютеров и смартфонов;
* работа без регистрации и подключения к интернету.

## Запуск на компьютере

1. Скачайте репозиторий через `Code → Download ZIP`.
2. Распакуйте архив.
3. Откройте файл `index.html` в браузере.

Установка программ, зависимостей и локального сервера не требуется.
